# docs/

The two documents required by COS750, written in LaTeX.

| Folder | Document | Main file |
|---|---|---|
| `SE_Document/` | Software Engineering document | `main.tex` |
| `ID_Document/` | Instructional Design document | `main.tex` |

## Master copy

The Overleaf projects are the master copy. The folders here are a snapshot of
their sources, taken when the repository was set up. When a document changes on
Overleaf, copy the changed files here in the same commit.

## Building

Upload a folder to Overleaf, or compile it locally with `latexmk -pdf main.tex`.
The PDFs are not committed; see `.gitignore`.
