# evaluation/

Materials for the usability study and the evaluation described in the ID document.

## Planned contents

- `consent.md`: the participant information and consent sheet, to be approved before
  use. Do not add participant names or student numbers to this folder.
- `task-script.md`: the tasks read to each participant, in order.
- `pre-post-probe.md`: the tracing test given before and after use.
- `questionnaire.md`: the five-point Likert items and the open question.

Results are stored outside the repository, in a location the group agrees on, so
that no personal data is committed.
